Agentic AI systems can make decisions, carry out tasks, and interact with their environment autonomously. This autonomy introduces security risks that go beyond classic AI vulnerabilities, including manipulation of API interactions, misuse of external tools and APIs, unsafe data or faulty API responses, and risks from insufficient API authentication and authorisation.

This thesis reviews the existing literature on AI security and API interactions, develops a classification of vulnerabilities specific to agentic AI, and evaluates it against examples such as open-source agents like AutoGPT or LangChain.
