This project investigates how bias propagates in multi-agent LLM systems when agents interact through external tools such as APIs, databases, or retrieval models. Using open-source agent frameworks, experiments will measure whether biased tools influence the agents that use them, whether de-biasing the tools alone is sufficient, and whether differently-initialised agents converge toward a dominant bias over time.

- **Type of work:** Bachelor thesis, Master thesis or project  
- **Field:** Trustworthy AI, with links to AI Engineering and Machine Learning
- **Institute:** Institute of Data Science (IDS), Centre for Artificial Intelligence (CAI), ZHAW
- **Prerequisites:** basic machine learning knowledge, ability to review and critically assess literature, basic programming skills (e.g. Python) for the experiments. Experience with frameworks such as LangChain or AutoGPT is a plus, not a requirement.
- **Language:** German or English
